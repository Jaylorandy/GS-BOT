# 🔍 输出目录没有文件的调试指南

## 问题描述

运行软件完成后，在输出目录没有看到任何图片文件。

---

## 🔧 新增的调试功能

我已经在最新版本中添加了详细的调试日志，帮助你找出问题所在。

### 新增的日志信息

1. **款号确认**
   - 显示即将处理的所有款号

2. **抓取统计**
   - 成功抓取的款式数量
   - 失败的款式数量
   - 总共抓取的图片数量

3. **目录创建**
   - 显示每个款式目录的创建路径

4. **详细错误信息**
   - 网络错误
   - HTTP 状态码
   - 文件写入错误
   - 下载超时

---

## 📋 诊断步骤

### 第一步：查看运行日志

运行一次任务后，仔细查看日志窗口，寻找以下关键信息：

#### 1. 款号确认
```
📋 即将处理 X 个款号: [款号列表]
```
✅ 如果看到这条日志，说明款号读取成功
❌ 如果没有看到，说明款号输入或 Excel 解析有问题

#### 2. 抓取统计
```
📊 抓取统计: 成功 X 个款式，失败 X 个款式，共 X 张图片
```
✅ 如果"共 X 张图片"是 0，说明没有抓取到任何图片
✅ 如果有数字，说明抓取成功，问题出在下载

#### 3. 目录创建
```
📁 创建目录: [路径]
```
✅ 如果看到这条日志，说明目录创建成功
❌ 如果没有看到，说明没有成功的款式

#### 4. 下载日志
```
⬇️ [已保存] 文件名 (大小 KB)
❌ [失败] 文件名: 错误信息
```
✅ 如果看到"已保存"，说明下载成功
❌ 如果看到"失败"，需要根据错误信息排查

## 🐛 常见问题和解决方案

### 问题 1：没有抓取到任何图片

**日志显示：**
```
📊 抓取统计: 成功 0 个款式，失败 X 个款式，共 0 张图片
```

**可能原因：**

#### 原因 1.1：款号格式错误
- 款号不是 7 位数字
- 款号包含字母或特殊字符

**解决方案：**
- 确保款号格式为：0123456（7 位数字）
- 检查 Excel 文件，确保款号在第二列

#### 原因 1.2：款号不存在
- 款号在 Zara 网站上不存在

**解决方案：**
- 在浏览器中访问 Zara 网站，手动输入款号验证
- 确认款号是否有效

#### 原因 1.3：网站访问受限
- 网络连接问题
- Zara 网站屏蔽了访问

**解决方案：**
- 检查网络连接
- 尝试使用 VPN（建议使用美国节点）
- 查看日志中的错误信息

#### 原因 1.4：网页结构变化
- Zara 网站更新了页面结构

**解决方案：**
- 暂时等待更新
- 联系开发者修复

---

### 问题 2：抓取成功但下载失败

**日志显示：**
```
📊 抓取统计: 成功 X 个款式，失败 0 个款式，共 X 张图片
```
但是：
```
❌ [失败] 文件名: 错误信息
```

**可能的错误信息：**

#### 错误 2.1：HTTP 403/404
```
❌ [失败] 0123456_F.jpg: HTTP 404 - Not Found
```

**原因：** 图片 URL 不存在或已过期

**解决方案：**
- 稍后重试
- 检查网络连接
- 使用 VPN 重试

#### 错误 2.2：下载超时
```
❌ [失败] 0123456_F.jpg: 下载超时
```

**原因：** 网络速度慢或连接不稳定

**解决方案：**
- 检查网络连接
- 降低下载并发数
- 使用更稳定的网络

#### 错误 2.3：网络错误
```
❌ [失败] 0123456_F.jpg: 网络错误: ECONNREFUSED
```

**原因：** 网络连接被拒绝

**解决方案：**
- 检查网络连接
- 检查防火墙设置
- 尝试使用 VPN

#### 错误 2.4：文件太小
```
❌ [失败] 0123456_F.jpg: 文件太小，可能是下载失败
```

**原因：** 下载的文件不完整

**解决方案：**
- 检查网络连接
- 重试下载
- 检查磁盘空间

---

### 问题 3：目录创建成功但没有文件

**日志显示：**
```
📁 创建目录: [路径]
```
但没有下载日志

**可能原因：**
- 并发下载任务全部失败
- 下载任务卡住

**解决方案：**
1. 降低下载并发数（改为 5-10）
2. 检查网络连接
3. 查看是否有错误日志
4. 重新运行任务

---

### 问题 4：输出目录路径错误

**日志显示：**
```
📁 输出目录已设为: [路径]
```

**检查步骤：**
1. 记录日志中显示的路径
2. 在 Finder 中前往该路径
3. 确认路径是否正确

**如果路径错误：**
- 重新选择输出目录
- 或使用默认的桌面路径

## 💡 解决方案总结

### 快速修复清单

根据日志信息，选择对应的解决方案：

| 日志特征 | 问题类型 | 解决方案 |
|---------|---------|---------|
| "共 0 张图片" | 没有抓取到 | 检查款号、使用 VPN |
| "HTTP 404" | 图片不存在 | 重试或换款号 |
| "下载超时" | 网络慢 | 降低并发、检查网络 |
| "网络错误" | 连接失败 | 使用 VPN、检查防火墙 |
| "文件太小" | 下载不完整 | 检查磁盘空间、重试 |

### 建议的配置

如果网络不稳定，使用以下配置：

```
标签页并发数：2
下载并发数：5
单次处理：1-5 个款号
```
