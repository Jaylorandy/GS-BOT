### 3. 主进程 (main.js)

#### 新增IPC处理器
```javascript
ipcMain.handle('annotate-excel', async (event, config) => {
  const annotateModule = require('./annotate_excel.js');
  const result = await annotateModule.annotateExcel(excelPath, outputDir, emitLog);
  return { success: true, outputPath: result };
});
```

### 4. 标注模块 (annotate_excel.js)

#### 核心功能

1. **checkStyleExists(styleId)**
   - 检查产品是否存在于Zara官网
   - 支持JavaScript渲染检测
   - 返回true/false/'javascript'

2. **checkDownloadedImages(styleId, outputDir)**
   - 检查本地是否已下载图片
   - 统计.jpg/.jpeg文件数量

3. **extractStyleId(styleNumber)**
   - 从款号字符串提取10位ID
   - 支持多种格式: 1934/470/807, 1934470807等

4. **annotateExcel(inputPath, outputDir, logCallback)**
   - 主标注函数
   - 读取Excel文件
   - 遍历所有款号
   - 检查状态并标注
   - 保存结果文件

#### 标注逻辑
```
读取Excel
  ↓
遍历每一行
  ↓
提取款号ID
  ↓
检查本地图片
  ├─ 有图片 → 绿色(成功)
  └─ 无图片 → 继续
      ↓
  检查产品是否存在
      ├─ 存在 → 黄色(存在但未下载)
      ├─ 需JS渲染 → 黄色(需JS渲染)
      └─ 不存在 → 红色(不存在)
  ↓
保存标注结果
```

## 已知限制

1. **网络依赖**
   - 标注功能需要访问Zara官网
   - 受网络状况影响

2. **反爬虫保护**
   - Zara有反爬虫机制
   - 部分产品可能无法准确判断

3. **颜色显示**
   - Excel中的颜色需要Excel等工具查看
   - 文本编辑器可能无法显示

4. **格式支持**
   - 仅支持.xlsx和.xls格式
   - 需要标准的Excel结构
