## 🎯 新增功能

### 面料信息智能分离

根据用户需求，现在可以**自动识别并分离外壳面料（Outer Shell）和里布面料（Lining）**，让面料信息更加清晰和专业。

---

## 📊 功能详解

### 1. **智能识别关键词**

系统会自动识别以下关键词来区分面料类型：

#### 外壳面料标识
```
✅ OUTER SHELL
✅ SHELL (非Lining上下文)
✅ Outer shell
```

#### 里布面料标识
```
✅ LINING
✅ Lining
```

#### 其他面料标识
```
✅ FILLING (填充物)
✅ PADDING (衬垫)
✅ Main material (主要材料)
```

---

### 2. **数据结构优化**

#### 修改前（v1.0.5及更早）
```json
{
  "composition": "OUTER SHELL: 80% Wool | 20% Polyester | LINING: 100% Viscose"
}
```

## 🔍 识别逻辑

### 解析流程

```
1. 定位面料信息段落
   ↓
2. 按行分析，识别类别标识
   ↓
3. 将后续材料信息归类到对应类别
   ↓
4. 分别存储到outerShell、lining、other字段
```

### 智能处理

#### 场景1: 标识和材料在同一行
```
输入: "OUTER SHELL: 80% Wool, 20% Polyester"
输出: outerShell = "80% Wool, 20% Polyester"
```

#### 场景2: 标识和材料分行
```
输入: 
  OUTER SHELL
  80% Wool
  20% Polyester
  
输出: outerShell = "80% Wool | 20% Polyester"
```

#### 场景3: 多个类别混合
```
输入:
  OUTER SHELL
  100% Polyester
  LINING
  100% Viscose
  
输出: 
  outerShell = "100% Polyester"
  lining = "100% Viscose"
```

## 🚀 技术实现

### 核心算法

```javascript
// 1. 定位面料信息段落
const compositionSection = findCompositionSection(allText);

// 2. 按行解析
const lines = compositionSection.split('\n');

// 3. 状态机识别类别
let currentCategory = 'other';
for (const line of lines) {
  if (line.includes('OUTER SHELL')) {
    currentCategory = 'outer';
  } else if (line.includes('LINING')) {
    currentCategory = 'lining';
  } else if (isMaterialLine(line)) {
    addToCategory(currentCategory, line);
  }
}
```

### 关键特性
- ✅ 状态机解析
- ✅ 大小写不敏感
- ✅ 支持同行和分行格式
- ✅ 自动去除标识符
- ✅ 智能拼接多行材料
