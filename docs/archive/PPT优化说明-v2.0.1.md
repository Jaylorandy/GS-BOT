# 📊 PPT生成优化 - v2.0.1

## 🎯 优化内容

### 1. 图片布局修复

#### 问题
- ❌ 只显示模特图
- ❌ 正反面图没有显示

#### 解决方案
✅ **增强图片查找逻辑**
- 支持更多图片类型匹配：`F`, `e1`, `2-1-p`, `front`（正面）
- 支持更多图片类型匹配：`B`, `e2`, `2-2-p`, `back`（背面）
- 支持更多模特图匹配：`X01`, `X02`, `X1`, `X2`, `01`, `02`
- 添加模糊匹配：如果精确匹配失败，尝试文件名包含关键词
- 添加备用方案：如果没有模特图，使用第一张可用图片

✅ **优化图片位置和尺寸**
```
模特图（左侧大图）:
  位置: (4.5", 0.5")
  尺寸: 4" × 6.5"

正面图（右上）:
  位置: (9.2", 0.5")
  尺寸: 3.5" × 3"

背面图（右下）:
  位置: (9.2", 4")
  尺寸: 3.5" × 3"
```

## 🐛 常见问题

### Q1: 图片还是没有显示
**A**: 检查：
1. 图片文件是否存在
2. 图片命名是否正确（款号_类型.扩展名）
3. 查看生成日志，确认是否找到图片

### Q2: 图片位置不对
**A**: 当前布局固定为：
- 模特图：左侧大图
- 正反面：右侧上下排列
- 如需调整，可修改Python脚本中的位置参数

### Q3: 字体显示不正常
**A**: 
- 确保系统已安装Arial字体
- macOS默认包含Arial
- 如果仍有问题，可以在脚本中改为其他字体（如Helvetica）
