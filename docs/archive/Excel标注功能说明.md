# Excel标注功能使用说明

## 功能概述

Zara Scraper Pro 现已集成Excel款号状态标注功能,可以自动检查Excel中款号的状态,并用不同颜色进行标注。

## 功能特点

- ✅ **自动检测**: 自动读取Excel中的款号
- 🎨 **颜色标注**: 用不同颜色区分款号状态
- 📊 **状态检查**: 检查产品是否存在于Zara官网
- 🖼️ **图片验证**: 检查本地是否已下载图片
- 💾 **一键下载**: 直接下载标注后的Excel文件

## 使用步骤

### 1. 启动应用

```bash
cd /Users/jaylorandy/zara-app
npm run dev
```

或直接运行已打包的应用程序。

### 2. 选择Excel文件

1. 在应用界面中,点击"Excel文件"输入框右侧的"选择文件"按钮
2. 选择包含款号的Excel文件(.xlsx或.xls格式)
3. Excel文件应包含以下列:
   - 第1列: 品牌
   - 第2列: 款号 (格式如: 1934/470/807 或 1934470807)

### 3. 选择输出目录(可选)

- 点击"输出目录"右侧的"选择文件夹"按钮
- 选择图片保存的目录
- 如果不选择,将使用应用默认目录

### 4. 点击"标注Excel"按钮

- 点击绿色的"标注Excel"按钮
- 应用将自动:
  1. 读取Excel文件
  2. 检查每个款号是否存在于Zara官网
  3. 检查本地是否已下载图片
  4. 用不同颜色标注状态
  5. 保存标注结果

### 5. 查看结果

- 在日志窗口中可以看到标注进度
- 标注完成后,结果将保存到原文件所在目录
- 文件名格式: `原文件名_标注结果.xlsx`

## 标注结果说明

### 状态列说明

| 状态 | 说明 | 操作建议 |
|------|------|----------|
| ✅ 成功 | 图片已成功下载到本地 | 可以直接使用 |
| ⚠️ 存在但未下载 | 产品存在但未下载图片 | 可以手动下载或使用抓取功能 |
| ⏳ 需JS渲染 | 产品存在但页面需要JavaScript渲染 | 手动访问网站下载 |
| ❌ 不存在 | 款号无效或产品已下架 | 检查款号是否正确 |

### 图片数量列

显示已下载的图片数量:
- 0: 未下载
- >0: 已下载的图片张数

### 颜色标识

虽然Excel文件中的颜色标注需要使用Excel查看,但日志中会明确显示每个款号的状态。

## 注意事项

1. **网络连接**: 标注功能需要访问Zara官网检查产品是否存在,请确保网络连接正常
2. **请求频率**: 为避免被反爬虫拦截,工具会在每次检查之间添加延迟
3. **输出目录**: 如果选择了输出目录,标注功能会检查该目录中是否有已下载的图片
4. **文件覆盖**: 标注结果会保存为新文件,不会覆盖原Excel文件

## 工作流程建议

### 完整工作流程

1. **准备Excel**: 创建包含款号的Excel文件
2. **标注检查**: 使用标注功能检查款号状态
3. **分类处理**:
   - 绿色(成功): 直接使用
   - 黄色(存在但未下载): 使用抓取功能下载
   - 红色(不存在): 检查款号或删除
4. **生成PPT**: 使用已有的PPT生成工具创建Lookbook

### 批量操作建议

1. 先对Excel进行标注,了解哪些款号需要处理
2. 对于黄色标记的款号,使用应用的抓取功能批量下载
3. 下载完成后,再次运行标注功能验证结果
4. 最后生成PPT或进行其他处理

## 常见问题

### Q: 标注后为什么没有颜色?

A: 颜色标注需要使用Excel或其他支持样式的工具查看。直接用文本编辑器打开可能无法显示颜色。

### Q: 为什么有些款号显示"需JS渲染"?

A: 这些产品的页面使用了JavaScript动态加载,简单的HTTP请求无法完整获取内容。建议手动访问网站查看。

### Q: 标注速度很慢怎么办?

A: 标注速度受网络和Zara网站响应速度影响。可以:
1. 检查网络连接
2. 稍后重试(网站可能繁忙)
3. 分批处理,每次标注少量款号

### Q: 如何批量抓取标注为黄色的款号?

A: 可以:
1. 将标注后的Excel中的款号复制到应用的"款号列表"输入框
2. 点击"开始抓取"按钮
3. 应用会自动抓取所有款号的图片

## 技术细节

### 款号ID提取

工具支持多种款号格式:
- `1934/470/807` → `1934470807`
- `1934470807` → `1934470807`
- `19344708` → `1934470800`

### 产品存在性检查

通过访问Zara官网URL检查:
```
https://www.zara.com/us/en/-p{ID[:8]}.html
```

### 图片下载检查

检查指定目录中是否有该款号的图片文件(.jpg或.jpeg格式)。
