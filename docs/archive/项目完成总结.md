## 🚀 快速开始

### 系统要求

| 组件 | 要求 |
|------|------|
| 操作系统 | macOS 10.15+ |
| 架构 | Apple Silicon (M1/M2/M3) |
| 浏览器 | Google Chrome（必须安装） |

### 安装步骤

#### 1️⃣ 安装 Google Chrome
```bash
brew install --cask google-chrome
```

#### 2️⃣ 安装应用
```bash
# 打开 DMG 文件
open /Users/jaylorandy/zara-app/release/Zara\ Scraper\ Pro-1.0.0-arm64.dmg

# 将应用拖拽到 Applications 文件夹
```

#### 3️⃣ 开始使用
```bash
# 启动应用
open -a "Zara Scraper Pro"
```

### 第一次使用

1. **启动应用**
   - 打开 Launchpad 或 Applications
   - 找到 "Zara Scraper Pro"
   - 点击启动

2. **输入款号**
   - 在"款号列表"中输入款号
   - 例如：`0123456, 9876543`

3. **开始抓取**
   - 点击"开始抓取"按钮
   - 等待进度条完成

4. **查看结果**
   - 图片保存到桌面 `Zara_Images` 文件夹
   - 按款式自动分类

### 架构设计

```
┌─────────────────────────────────────┐
│         Electron 主进程            │
│  ┌────────────┐  ┌────────────┐  │
│  │  main.js   │  │ IPC 通信   │  │
│  │ (爬虫引擎)  │  │            │  │
│  └────────────┘  └────────────┘  │
└─────────────────────────────────────┘
           ↕ (IPC)
┌─────────────────────────────────────┐
│      Electron 渲染进程              │
│  ┌────────────┐  ┌────────────┐  │
│  │  App.jsx   │  │ preload.js │  │
│  │  (UI 界面)  │  │ (安全桥接)  │  │
│  └────────────┘  └────────────┘  │
└─────────────────────────────────────┘
           ↓
┌─────────────────────────────────────┐
│     Google Chrome 浏览器            │
│    (用于网页抓取)                  │
└─────────────────────────────────────┘
```

**解决方案：**
```bash
# 安装 Google Chrome
brew install --cask google-chrome

# 或从官网下载
# https://www.google.com/chrome/
```

### 问题 2：应用无法启动

**解决方案：**
```bash
# 右键点击应用 → 选择"打开"
# 在弹出的对话框中点击"打开"
```

### 问题 3：抓取失败

**可能原因：**
- 网络连接不稳定
- 款号不存在
- Zara 网站更新

**解决方案：**
- 检查网络连接
- 验证款号是否正确
- 尝试使用 VPN
- 查看运行日志
