# 🚀 快速打包指南

## 方法一：使用自动化脚本（最简单）

```bash
cd /Users/jaylorandy/zara-app
./package.sh
```

脚本会自动完成所有步骤，包括构建和打包。

## 方法二：手动执行命令

### 步骤 1: 构建前端（已完成）
```bash
cd /Users/jaylorandy/zara-app
npm run build
```

### 步骤 2: 打包应用
```bash
npm run dist
```
或者
```bash
npx electron-builder --mac --publish=never
```

## 📊 打包进度提示

打包过程中你会看到类似的输出：

```
  • electron-builder  version=26.8.1 os=24.1.0
  • building        target=macOS zip arch=x64 file=release/Zara Scraper Pro-1.0.0-mac.zip
  • building        target=dmg arch=x64 file=release/Zara Scraper Pro-1.0.0.dmg
```

这表示正在打包中，请耐心等待 3-8 分钟。

## ✅ 打包成功标志

当看到以下输出时表示打包成功：

```
  • building        target=dmg arch=x64 file=release/Zara Scraper Pro-1.0.0.dmg
  • building        target=macOS zip arch=x64 file=release/Zara Scraper Pro-1.0.0-mac.zip

  done in XXs
```

## 📁 安装包位置

成功后，安装包位于：
- `./release/Zara Scraper Pro-1.0.0.dmg`

## 🎯 安装步骤

1. 双击 `Zara Scraper Pro-1.0.0.dmg`
2. 在弹出的窗口中，将应用图标拖拽到 "Applications" 文件夹
3. 打开 Launchpad 或 Applications 文件夹
4. 找到并启动 "Zara Scraper Pro"

## 🐛 常见问题

### 1. 打包时提示权限错误
```bash
chmod +x node_modules/.bin/electron-builder
```

### 2. 打包时提示磁盘空间不足
清理磁盘空间，确保至少有 1GB 的空闲空间

### 3. 打包后无法打开应用
右键点击应用 -> 选择"打开" -> 在弹出的对话框中点击"打开"

### 4. 应用图标不显示
这通常是因为首次运行，等待系统缓存更新即可

## 💡 提示

- 打包期间请保持网络连接（需要下载依赖）
- 建议在稳定的网络环境下打包
- 如果打包失败，可以先尝试清理缓存：
  ```bash
  rm -rf node_modules/.cache
  rm -rf dist
  ```
