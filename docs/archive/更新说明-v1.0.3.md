# 更新说明 v1.0.3 - Excel标注功能

## 新增功能

### 🎨 Excel款号状态标注

本次更新新增了Excel款号状态标注功能,可以自动检查和标记Excel中款号的状态。

#### 主要特性

- **自动检测**: 自动读取Excel中的款号信息
- **状态检查**: 检查每个款号是否存在于Zara官网
- **图片验证**: 检查本地目录中是否已下载图片
- **颜色标注**: 用不同颜色区分不同状态
- **一键保存**: 直接下载标注后的Excel文件

#### 标注状态

| 颜色 | 状态 | 说明 |
|------|------|------|
| 🟢 绿色 | ✅ 成功 | 图片已成功下载 |
| 🟡 黄色 | ⚠️ 存在但未下载 | 产品存在但未下载图片 |
| 🔴 红色 | ❌ 不存在 | 款号无效或产品已下架 |
| ⬜ 白色 | 空 | 空行或无效款号 |

## 界面更新

### 新增标注功能区域

在配置面板下方新增了"Excel标注功能"区域:

```
┌─────────────────────────────────────┐
│ Excel标注功能                        │
│ ┌─────────────────────────────────┐ │
│ │ 自动检查Excel中款号的状态...    │ │

└─────────────────────────────────────┘
```

### 按钮状态

- **可用**: 已选择Excel文件且没有正在运行的任务
- **禁用**: 未选择Excel文件或有任务正在运行
- **标注中**: 按钮显示"标注中..."

## 使用方法

### 1. 选择Excel文件

点击"Excel文件"输入框右侧的"选择文件"按钮,选择包含款号的Excel文件。

### 2. 点击标注按钮

点击绿色的"标注Excel"按钮,系统将自动:
1. 读取Excel文件
2. 检查每个款号是否存在于Zara官网
3. 检查本地是否已下载图片
4. 用不同颜色标注状态
5. 保存标注结果到原文件所在目录

### 3. 查看结果

在日志窗口可以看到详细的标注过程和结果。

标注完成后,结果文件将保存为:
```
原文件名_标注结果.xlsx
```

## 技术细节

### 标注流程

```
1. 读取Excel文件
   ↓
2. 遍历每一行款号
   ↓
3. 提取款号ID
   ↓
4. 检查本地图片
   ├─ 有图片 → 绿色(成功)
   └─ 无图片 → 继续
       ↓
5. 检查产品是否存在
   ├─ 存在 → 黄色(存在但未下载)
   ├─ 需JS渲染 → 黄色(需JS渲染)
   └─ 不存在 → 红色(不存在)
   ↓
6. 保存标注结果
```

### 网络请求

为避免被Zara反爬虫拦截:
- 每次检查之间添加500ms延迟
- 使用标准User-Agent
- 设置10秒超时

### 错误处理

- 网络错误: 标记为不存在
- 超时: 标记为不存在
- 无效款号: 跳过并记录日志

## 使用场景

### 场景1: 检查款号有效性

使用标注功能快速检查Excel中的款号是否有效:

1. 导入Excel
2. 点击标注
3. 查看哪些款号被标记为红色(不存在)
4. 修正或删除无效款号

### 场景2: 批量抓取前检查

在批量抓取前使用标注功能:

1. 标注Excel,了解哪些款号需要下载
2. 复制标注为黄色的款号到款号列表
3. 运行抓取功能
4. 下载完成后再次标注验证

### 场景3: 验证下载结果

批量下载后验证结果:

1. 标注Excel
2. 查看哪些款号变成了绿色(成功)
3. 对仍然是黄色的款号进行处理

## 性能优化

- 并发控制: 避免同时发送过多请求
- 延迟处理: 每隔几行添加延迟
- 缓存结果: 避免重复检查相同款号(未来版本)

## 已知问题

1. **颜色显示**: Excel中的颜色需要使用支持样式的工具查看(如Excel、Numbers等)
2. **网络依赖**: 标注功能需要访问Zara官网,受网络影响
3. **JS渲染**: 某些产品页面需要JavaScript,可能无法准确判断
