## 🚀 安装步骤

### 1. 安装应用程序
1. 双击 `Zara Scraper Pro-1.0.0-arm64.dmg`

或使用requirements.txt：

## 🎯 功能使用

### 功能01: Zara Scraper（产品抓取）

#### 快速开始
1. 启动应用，点击顶部 **"🔍 Zara Scraper"** 标签
2. 输入款号（例如：`1934/470/807`）或导入Excel文件
3. 选择输出目录
4. 点击 **"🚀 开始抓取"**

#### 支持的款号格式
- ✅ `1934/470/807` (标准格式，推荐)
- ✅ `0155/325/518` (带前导0)
- ✅ `193447080` (9位纯数字)

#### 高级设置
- **并发标签页**: 2-3个（推荐）
- **下载并发数**: 5-10个

---

### 功能02: Slides Maker（PPT制作）

#### 快速开始
1. 点击顶部 **"📊 Slides Maker"** 标签
2. 点击 **"选择文件夹"**，选择包含产品图片的文件夹
   - 例如：`/Users/jaylorandy/Desktop/zara`
3. 配置选项（可选）
4. 点击 **"🎨 生成PPT"**

#### 文件夹结构要求
```
zara/
├── 1934470807/
│   ├── 1934470807_info.json    ← 产品信息
│   ├── 1934470807_F.jpg         ← 正面图
│   ├── 1934470807_B.jpg         ← 背面图
│   ├── 1934470807_X01.jpg       ← 模特图
│   └── ...
├── 0155325518/
│   └── ...
└── ...
```

#### 配置选项说明

**内容设置**:
- ☑️ **显示价格**: 在PPT中显示商品价格
- ☑️ **显示面料成分**: 显示外壳和里布材质
- ☑️ **显示商品描述**: 显示产品描述文字

**布局设置**:
- 🎯 **模特图 + 正反面** (推荐): 左侧大模特图，右侧正反面小图
- 📐 **网格布局**: 多张图片网格排列
- 🎞️ **轮播布局**: 单张图片展示

**排序方式**:
- 按款号排序（默认）
- 按名称排序
- 按价格排序

## 💡 使用技巧

### Zara Scraper技巧
1. **小批量处理**: 每次10-20个款号，成功率更高
2. **使用Excel导入**: 批量处理更方便
3. **检查款号格式**: 优先使用带斜杠的标准格式
4. **网络稳定**: 避免使用VPN，使用稳定网络

### Slides Maker技巧
1. **文件夹整理**: 
   - 每个款式独立文件夹
   - 文件夹名=款号
   - 包含`_info.json`文件

2. **图片命名规范**:
   - 正面: `款号_F.jpg`
   - 背面: `款号_B.jpg`
   - 模特图: `款号_X01.jpg` 或 `款号_01.jpg`
   - 细节图: `款号_D1.jpg`, `款号_D2.jpg`...

3. **优化建议**:
   - 图片大小控制在5MB以内
   - 款式数量建议<50个
   - 使用高质量图片以获得最佳效果

## ⚠️ 常见问题

### Q1: 应用无法打开，提示"无法验证开发者"
**A**: 
1. 右键点击应用 → 选择"打开"
2. 或在"系统偏好设置" → "安全性与隐私"中点击"仍要打开"

### Q2: Slides Maker提示"无法启动Python"
**A**: 
```bash
# 检查Python是否安装
python3 --version

# 安装依赖
pip3 install python-pptx Pillow
```

### Q3: PPT生成失败
**A**: 检查：
1. ✅ Python3已安装
2. ✅ python-pptx和Pillow已安装
3. ✅ 文件夹结构正确
4. ✅ 有足够的磁盘空间

### Q4: 图片抓取不全
**A**: 
1. 检查款号格式是否正确
2. 降低并发数（改为2-3个标签页）
3. 检查网络连接
4. 查看日志中的错误信息

### Q5: 生成的PPT没有图片
**A**: 
1. 检查图片文件是否存在
2. 检查图片命名是否符合规范
3. 确保图片格式为jpg/png/webp
4. 检查文件夹权限
