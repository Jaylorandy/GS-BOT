## 🚀 完成打包的步骤

### 方法一：使用自动化脚本（推荐）

在终端中执行：

```bash
cd /Users/jaylorandy/zara-app
./build.sh
```

### 方法二：手动执行命令

```bash
cd /Users/jaylorandy/zara-app
npm run dist
```

## ⏱️ 预计时间

- Electron 打包通常需要 **3-8 分钟**
- 时间取决于你的电脑性能

## 📁 打包完成后

打包成功后，你会在 `zara-app/release` 文件夹中找到：

- **Mac**: `Zara Scraper Pro-1.0.0.dmg` - 可以直接双击安装
- **应用图标**: 会自动使用默认图标或你指定的图标

## 🎯 安装和使用

1. 双击 `.dmg` 文件打开
2. 将应用拖拽到 Applications 文件夹
3. 在 Launchpad 或 Applications 中找到 "Zara Scraper Pro"
4. 点击启动应用

## 🎨 应用功能

- ✅ 支持手动输入款号
- ✅ 支持从 Excel 文件导入款号
- ✅ 自动下载并分类产品图片
- ✅ 实时显示抓取进度
- ✅ 可配置并发数
- ✅ 精美的 UI 界面

## 📝 注意事项

- 首次运行时会自动下载 Chromium 浏览器（如果使用 Puppeteer）
- 确保有稳定的网络连接
- 建议使用美国 IP 或 VPN 以访问 Zara 美国官网

## 🐛 常见问题

### 打包失败怎么办？

检查是否有足够的磁盘空间（至少需要 1GB 空闲空间）

### 应用无法打开？

右键点击应用，选择"打开"，允许来自未知开发者的应用

### 找不到 Excel 文件选择功能？

确保你选择的是 Excel 文件所在的**文件夹**，而不是文件本身
