# Zara Scraper Pro - Windows 版本使用说明

## 📦 安装

1. 双击运行 `Zara Scraper Pro Setup 1.0.0.exe`
2. 按照安装向导完成安装
3. 安装完成后，会在桌面创建快捷方式

## 🌐 系统要求

### 必需软件
- **Windows 10 或更高版本**（64位）
- **Google Chrome 浏览器**（必须安装，程序会自动查找并使用）

### Chrome 安装位置
程序会自动在以下位置查找 Chrome：
- `C:\Program Files\Google\Chrome\Application\chrome.exe`
- `C:\Program Files (x86)\Google\Chrome\Application\chrome.exe`
- `%LOCALAPPDATA%\Google\Chrome\Application\chrome.exe`

如果程序提示"未找到 Chrome 浏览器"，请：
1. 下载并安装 Google Chrome：https://www.google.com/chrome/
2. 确保安装到默认位置

## 🚀 使用方法

### 方式一：手动输入款号
1. 在"款号列表"输入框中输入款号，用逗号分隔
   ```
   例如：4772049620, 4764004251, 0123456789
   ```
2. 点击"开始抓取"

### 方式二：从 Excel 导入
1. 准备 Excel 文件，格式要求：
   - 第一行：表头（可忽略）
   - 第二列：款号（必填）
   - 示例：
     ```
     | 序号 | 款号      | 品牌  |
     | 1    | 4772049620 | Zara  |
     | 2    | 4764004251 | Zara  |
     ```
2. 点击"选择文件"按钮
3. 选择 Excel 文件（.xlsx 或 .xls）
4. 点击"开始抓取"

### 方式三：混合使用
可以同时使用 Excel 导入和手动输入款号

## 📁 输出目录

默认输出到桌面的 `Zara` 文件夹：
```
C:\Users\{用户名}\Desktop\Zara\
├── 4772049620\
│   ├── 4772049620_F.jpg       (平铺正面)
│   ├── 4772049620_B.jpg       (平铺反面)
│   ├── 4772049620_01.jpg      (模特主图)
│   ├── 4772049620_02~09.jpg   (模特多角度)
│   └── 4772049620_info.json   (产品详细信息)
├── 4764004251\
│   └── ...
└── summary.json               (所有款式汇总)
```

### 产品信息 JSON 格式
每个款号的 `info.json` 包含：
```json
{
  "styleNumber": "4772049620",
  "name": "产品名称",
  "price": "$59.90",
  "colorRef": "颜色参考 | 编号",
  "description": "产品描述文本...",
  "url": "https://www.zara.com/us/en/-p04772049.html",
  "images": {
    "F": "正面图URL",
    "B": "反面图URL",
    "01": "模特主图URL",
    ...
  }
}
```

## 🖼️ 图片分类说明

| 标签 | 含义 | 说明 |
|------|------|------|
| F | Flat Front | 平铺正面图 |
| B | Flat Back | 平铺反面图 |
| D1~D2 | Detail | 细节图 |
| 01 | Model Main | 模特主图 |
| 02~09 | Model Angles | 模特多角度图 |
| X01~X99 | Unknown | 未知类型图片 |

## ⚙️ 配置选项

### 标签页并发数
- **作用**：同时打开的浏览器标签页数量
- **推荐值**：3
- **注意**：设置过高可能导致被 Zara 限流

### 下载并发数
- **作用**：同时下载的图片数量
- **推荐值**：10
- **范围**：1-50

## 📊 运行日志

程序运行时会显示详细日志：
- 🟢 **绿色**：成功信息
- 🔴 **红色**：错误信息
- 🟡 **黄色**：警告信息
- 🔵 **青色**：普通信息

### 常见错误处理

| 错误信息 | 原因 | 解决方法 |
|----------|------|----------|
| 未找到 Chrome 浏览器 | 未安装或未安装在默认位置 | 安装 Google Chrome 到默认路径 |
| 没有抓取到任何图片 | 款号错误或页面结构变化 | 检查款号是否正确 |
| 抓取超时 | 网络连接慢 | 检查网络连接，重试 |
| 下载失败 | 图片 URL 无效或网络问题 | 查看具体错误信息，手动访问 URL 验证 |

## 🔍 故障排查

### 问题：程序启动失败
1. 检查是否已安装 Google Chrome
2. 尝试以管理员身份运行
3. 检查防火墙/杀毒软件是否拦截

### 问题：找不到 Chrome
1. 打开 Chrome，访问 `chrome://version/`
2. 确认 Chrome 安装在 Program Files 或 Program Files (x86)
3. 如果自定义安装路径，请修改配置

### 问题：抓取失败率高
1. 降低"标签页并发数"（改为 1 或 2）
2. 检查网络连接是否稳定
3. 确认款号格式正确（7位或10位数字）

### 问题：图片下载失败
1. 检查磁盘空间是否充足
2. 检查网络连接
3. 降低"下载并发数"

## 💡 使用建议

1. **首次使用**：先用 1-2 个款号测试，确认程序正常运行
2. **批量抓取**：建议分批次处理，每次 5-10 个款号
3. **网络优化**：确保网络连接稳定，避免断线重连
4. **数据备份**：重要数据及时备份到其他位置

## 📝 款号格式说明

Zara 款号有两种格式：
- **7 位**：传统格式，如 `0123456`
- **10 位**：新格式，如 `4772049620`

程序会自动识别并处理两种格式。

## 📞 技术支持

2. `summary.json` 中的失败款号及原因
3. Windows 事件查看器中的应用程序日志
