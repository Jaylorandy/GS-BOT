# GS Bot

GS Bot is an Electron desktop app for apparel operations workflows. It combines scraping, PPT generation, image organization, garment cutout, OCR configuration, PDF compression, product analysis, and LAN file access in a single local tool.

## Main Workspaces

- `Zara Scraper`: scrape product assets and metadata from supported retail sites.
- `Slides Maker`: generate PPT decks from organized image sets and OCR metadata.
- `Image Organizer`: rename and group garment or fabric images from label photos.
- `Garment Cleaner`: create white-background or transparent garment cutouts locally.
- `Label OCR`: manage shared OCR rules used by deck generation and image organization.
- `PDF Squeezer`: reduce PDF size by recompressing embedded images.
- `Product Analysis`: build report-style outputs from product inputs.
- `LAN Drive`: browse shared files on local network storage.

## Stack

- Electron app entry: [main.js](/Users/jaylorandy/GS Bot-app/main.js)
- Frontend: React 18 + esbuild bundle pipeline
- Desktop bridge: [preload.js](/Users/jaylorandy/GS Bot-app/preload.js)
- Python utilities for slides, PDF, and garment processing
- Optional local model runtimes for RMBG, SegFormer, and OCR-related flows

## Scripts

- `npm run dev`: start the Vite dev server for frontend iteration.
- `npm run build`: build frontend assets into `dist/`.
- `npm run dist` or `npm run dist:mac`: build the macOS distribution.
- `npm run mac:local`: run the app locally on macOS.
- `npm run prepare:win-runtime`: prepare bundled Windows runtime assets.
- `npm run dist:win`: build the Windows installer and zip output.
- `npm run test:regression`: run the project regression checks.
- `npm run license:generate`: generate license keys from the CLI tool.
- `npm run license:gui`: open the Electron-based license generator.

## Local Requirements

- Node.js and npm
- Python 3 for Python-backed workflows in development
- Electron dependencies from `package-lock.json`
- Chrome or Chromium for scraping workflows
- Optional model files for:
  - RMBG 2.0 garment cutout
  - SegFormer garment-boundary refinement
  - OCR runtimes used by label workflows

## Build Notes

- Frontend production builds are generated by [scripts/build-frontend.js](/Users/jaylorandy/GS Bot-app/scripts/build-frontend.js), not Vite's default build command.
- macOS packaging is handled by [scripts/build-mac-distribution.js](/Users/jaylorandy/GS Bot-app/scripts/build-mac-distribution.js).
- Windows packaging is handled by [scripts/build-windows-installer.js](/Users/jaylorandy/GS Bot-app/scripts/build-windows-installer.js) and depends on prepared runtime assets.
